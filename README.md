#  Discord Academy

Um site criado para ensinar pessoas a criarem, configurarem e gerenciarem servidores no Discord de maneira simples e prática.

##  Sobre o Projeto

O Discord Academy é um projeto desenvolvido por um estudante de 16 anos com o objetivo de ajudar iniciantes a aprenderem tudo sobre a criação de servidores no Discord, desde os primeiros passos até configurações mais avançadas.

##  Objetivos

* Ensinar como criar um servidor no Discord.
* Explicar a função dos cargos e permissões.
* Mostrar como organizar canais de texto e voz.
* Apresentar bots úteis para moderação e entretenimento.
* Compartilhar dicas para manter uma comunidade organizada e segura.

##  Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

##  Conteúdo do Site

* Criação de servidores
* Configuração de cargos
* Organização de canais
* Adição de bots
* Segurança e moderação
* Dicas para crescimento da comunidade

##  Desenvolvedor

Projeto desenvolvido por um estudante de **16 anos**, com foco em aprendizado, desenvolvimento web e compartilhamento de conhecimento sobre Discord.
